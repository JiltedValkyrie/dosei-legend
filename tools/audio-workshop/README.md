# Audio workshop

Play any US 1.2 sound effect or music sequence on the PC.

Launch with `open-audio-workshop.bat`. Needs Python with Tkinter.

- List is sorted by type: Player, Item, Environment, Enemy, System, Ocarina, Voice, then Music.
- Search matches the name. Type dropdown filters one bank.
- Play and Stop. Double-click a row to play.
- SFX preview is the channel's notes for about 1.6 seconds (samples, or a simple tone when the note is synthetic).
- Music preview uses the shared sequence baker for about 8 seconds. Sequences the baker cannot read show the error and do not play.
- No import or export.
